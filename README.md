# model-router-budget

A beginner-friendly FastAPI backend skeleton for an AI model router with budgets.

This project only includes the initial structure and a few simple starter files so you can build the real logic step by step.

## Run the project

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Then open:

```text
http://127.0.0.1:8000/docs
```
